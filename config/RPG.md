# 安安大冒險

`cmds/rpg.py` 由 `ourbot.py` 自動載入。主要玩家斜線指令如下：

| 指令 | 功能 |
| --- | --- |
| `/邀請 [成員]` | 不指定成員時在目前頻道張貼公開邀請函；指定時私訊僅限該成員的邀請函 |
| `/冒險` | 開啟僅自己可見的「安安大冒險」主選單，顯示角色、等級、金幣 |
| `/冒險者 [成員]` | 公開顯示自己或指定成員的冒險者名片；不公開金幣、背包與每日活動量 |
| `/討伐通知 [操作] [類型]` | 分別領取或取消一般／中階／高階討伐通知，也可一次操作全部 |
| `/冒險區域 [操作]` | 管理員查看、建立／匯入或修復冒險分類、頻道與身分組 |
| `/排行榜` | 查看本伺服器累積 XP 前十名 |
| `/生成討伐` | 管理員生成自訂討伐，保留原選填參數 |

主選單有「裝備／能力」、「技能」、「背包」、「商店」、「轉職」、「生活」、「移動」、「展示名片」、「說明」九個按鈕。「展示名片」可從背包選擇一件公開展示品；安安評語由本機固定規則產生，不呼叫 AI 或消耗模型 token。「移動」可前往瑪格的占卜室。各頁在同一則私人訊息切換，並提供「返回主選單」、「重新整理」、「關閉」。切頁後舊按鈕失效，只有原使用者可操作；閒置三分鐘後重新使用 `/冒險` 開啟。

新玩家必須先接受帶有夏目安安固定邀請詞的邀請函，才會正式建立角色、取得 Lv.1 民兵初始資料與 T1 木棒，並獲得 `.env` 的 `RPG_ADVENTURER_ROLE_IDS` 所配置、屬於該伺服器的冒險者身分組。未指定成員的公開邀請可由多位尚未加入者使用；指定成員的私訊邀請僅限收件者且成功後失效。邀請按鈕與狀態會保存，Bot 重啟後仍可使用。接受前的文字與語音活動不建立玩家資料，也不累積冒險 XP。Bot 需要管理身分組權限，且最高身分組位置必須高於冒險者身分組。

背包每頁十種物品，用上一頁／下一頁按鈕翻頁。轉職先選職業、再按確認，Lv.10 起可用；早期補給在轉職時自動發放，不再需要領取補給指令。原角色、裝備、技能、商店、背包、轉職與說明指令已整合進主選單。討伐仍由頻道公告按鈕報名。重啟並完成 Discord 指令同步後，新的指令列表生效。

## 預設規則

- 每人、每個伺服器的文字與語音 XP 分別有每日基礎上限：文字 1,000、語音 3,000，依下述聊天成長倍率調整。台灣時間（UTC+8）每日 00:00 換日，原文字冷卻仍保留；討伐 XP 不計入。主選單與裝備／能力頁顯示當日已獲得／目前等級的實際上限。
- `[rpg].text_daily_xp_limit`、`voice_daily_xp_limit` 可調整上限，設為 0 代表該來源不發經驗。最後一次只發剩餘額度；超額部分丟棄、不累積至隔天。語音按完整分鐘結算時的台灣日期計入（跨午夜的分鐘計入結算日），持續語音不需重新加入。
- 每日額度與總 XP 同一筆資料庫交易保存，重啟不重置額度。功能上線前的聊天 XP 無來源紀錄，不追溯扣當日額度；降低上限後若已超額，當日停止發放且不扣回既有 XP。

- 文字至少 3 個非空白字元，每 60 秒獲得基礎 15 XP，再套用聊天成長倍率。同一人在同一伺服器跨頻道共用冷卻；重啟不會重置冷卻。不計私訊、Bot、Webhook、系統訊息、純附件及編輯訊息。
- 一般語音頻道至少 2 位未靜音、未拒聽的真人，每位每完整分鐘獲得基礎 10 XP，再套用聊天成長倍率。AFK、舞台頻道、被壓制的成員不列入。Bot 不需要加入語音；以成員的語音狀態及參與時間計算，並不偵測實際說話，無法完全防止掛機。
- 語音每 15 秒及語音狀態變更時結算。離開或不再符合條件時結算完整分鐘，丟棄未滿一分鐘的餘額。換到仍符合條件的頻道可延續時間。Bot 斷線、重啟、伺服器暫時無法使用時清除尚未結算的時間，不補發離線經驗。
- 採用 [RuneScape 標準經驗曲線](https://runescape.wiki/w/Experience)（一般技能，非 Invention），Lv.1 為 0 XP；升至 Lv.L 的累積門檻為 `floor(sum(floor(n + 300 × 2^(n/7)), n=1..L-1) / 4)`。例如 Lv.2 = 83、Lv.50 = 101,333、Lv.99 = 13,034,431、Lv.120 = 104,273,167 XP。
- 本 Bot 等級上限先設為 Lv.120；滿級後仍累積 XP 排名，不顯示下一級。本次只沿用經驗曲線，未引入 RuneScape 的 200M XP 上限與虛擬等級。既有累積 XP 保留，顯示等級依新曲線重新計算，不需要資料庫遷移。
- Lv.1–9 為民兵，Lv.10 起可以主動轉職；未選職業者即使超過 Lv.10 仍顯示民兵。職業選定後依等級自動晉升，角色標題改為階段與職業名稱。
- 聊天成長倍率為 `max(1, (當級升級需求 / Lv.10 升至 Lv.11 的需求)^(1/3))`。文字單次 XP、語音每分鐘 XP 與各來源每日上限皆乘此倍率後向下取整；以整數比較求三次方根，避免浮點誤差。Lv.1–10 維持基礎值，Lv.120 沿用 Lv.119→120 的需求。每次結算依發放前等級計算；語音先算每分鐘整數 XP，再乘完整分鐘數。升級後下一次結算與畫面上限同步提高，當日已領 XP 不重置。設定上限為 0 仍停發；既有總 XP、每日紀錄及討伐／生活技能獎勵不改寫。
- 每個伺服器獨立累積，職業與裝備也獨立保存；排行榜保留曾參與但已離開的成員。此版已有自動討伐、技能策略、XP、飾品掉落與金幣商店，支援物品給予與商店收購，尚無雙方交換交易及自由配點。

新角色初始持有並裝備 T1 木棒：攻擊 +6、防禦 +6、穩定度 80–120%，約為 Lv.1 裸身攻擊與防禦的 20%，全職業、Lv.1 可用。既有角色首次讀取時補發一次，已有武器不替換；主動卸下後不會自動穿回。未裝備武器的玩家普攻與傷害技能無法造成傷害，治療和防禦技能仍可使用；怪物不受限制。新規則套用於之後開戰的討伐，已開戰的舊快照維持原行為。

## 職業、晉升與裝備

| 階段 | 預設等級 | 飾品格 |
| --- | --- | --- |
| 民兵 | 1 起，未轉職 | 1 |
| 早期 | 10 起，已轉職 | 2 |
| 無前綴 | 20 | 3 |
| 老練 | 50 | 4 |
| 精銳 | 90 | 5 |

例如「早期騎士 → 騎士 → 老練騎士 → 精銳騎士」。後三個晉升門檻可在 `[rpg]` 的 `regular_level`、`veteran_level`、`elite_level` 調整，必須大於 10 且嚴格遞增。若管理員提高門檻，未達需求的裝備和鎖定飾品格停止提供加成，物品仍保留，可卸下或移至可用格位。

裝備欄只有武器、套裝各一格，以及隨階段解鎖的飾品格。每個職業有四階武器與套裝，共 32 件職業裝備；另有生命護符、力量指環、堅韌徽章、靈巧吊墜、信仰念珠五種通用飾品，各提供一項能力 +3。每件武器、套裝與飾品都有獨立實例編號，重複討伐裝備會分別保留；同名飾品仍限穿一件，改穿另一格會移動，替換或卸下不會失去物品。

`/冒險 → 出戰配置` 為每位玩家提供三個免費配置格，可自行命名，並保存目前職業、各欄位的裝備實例、三個主動技能的開關／順位／單一條件／目標，以及 Lv.50 職業被動。套用時會一併轉職並原子替換整套內容；若裝備已出售或送出、等級不足，或技能與被動尚未解鎖，整套不會套用並會顯示原因。配置不保存料理或藥水。染色與刺繡附著於原裝備實例，因此同一實例後續加工不必重新保存；換成另一件同名裝備則需覆寫配置。

首次建立角色時發放並穿上木棒；首次轉職另發放早期職業武器、套裝及五種基本飾品，並自動穿上早期武器、套裝。木棒、早期職業裝備與五種免費飾品不可給予，但卸下後可在商店以 0 金幣出售。出售後不會因開啟角色功能自動補回；任何等級都能在轉職頁按「重新領取補給」補回木棒，已轉職角色也會同時補回目前職業缺少的早期裝備與免費飾品。切換職業時仍會補發該職業缺少的早期裝備及缺少的免費飾品。補發只補背包中缺少的物品，不會疊加仍持有的同款。自動補給不會發進階裝備；無前綴／老練／精銳武器與套裝只能在 `/冒險 → 商店` 購買，每件分別 500／1,500／4,000 金幣，需符合目前職業與等級。購入後用 `/冒險 → 裝備／能力` 自行換上。商店不允許重複購買，扣款與入庫同一筆交易，失敗一起回滾。可將非綁定物品給予其他成員，或賣回商店。

換職保留 XP 與全部背包，重新依新職業計算能力，卸下所有穿戴並換上新職業武器、套裝；飾品需重新穿戴。舊職業專屬裝備留在背包，但不能穿戴。背包可用翻頁按鈕查閱全部物品。

`/冒險 → 裝備／能力` 不需輸入參數：開啟私人互動面板，顯示等級／職業、五項能力（含飾品加成）、戰鬥數值及所有已解鎖裝備欄。先從第一個下拉選單選武器、套裝或飾品格，再從第二個選單選可用物品，按「穿戴」；按「卸下」可移除所選格位的物品。物品選單只列背包中符合當前職業、等級與欄位的裝備。空背包會停用物品選單與穿戴按鈕。

每次操作都重新檢查角色狀態並更新原面板的能力值，不會另外洗頻。「重新整理」可讀取其他指令造成的職業、等級或背包變動。「關閉」或閒置 3 分鐘會結束面板，重新使用 `/冒險 → 裝備／能力` 即可開啟；只有開啟者可操作。這是 Discord 訊息內的互動面板，不會開啟外部視窗。

## 能力值

五項名稱固定為生命力、力氣、耐力、靈巧、信仰。Lv.1 各為 10；升至 Lv.2–10 每項每級 +2。從 Lv.11 起依職業成長，民兵仍每項 +2：

| 職業 | 生命力 | 力氣 | 耐力 | 靈巧 | 信仰 |
| --- | ---: | ---: | ---: | ---: | ---: |
| 裝甲步兵（攻守均衡） | 3 | 3 | 2 | 1 | 1 |
| 騎士（承受傷害） | 4 | 1 | 3 | 1 | 1 |
| 弓兵（遠程輸出） | 2 | 3 | 1 | 3 | 1 |
| 僧侶（治療支援） | 2 | 1 | 1 | 2 | 4 |

每次晉升再增加兩倍該職業每級成長值，裝備額外加成另計。晚轉職或換職都重新套用完整成長，不會因轉職時間不同少拿能力。角色面板將成長後的能力、飾品加成與武器／套裝直接加成分開顯示。

戰鬥數值：HP = 50 + 生命力 ×10；防禦 = 耐力 ×3；治療量 = 信仰 ×3。攻擊依職業換算：裝甲步兵 = 力氣 ×3；弓兵 = 力氣 + 靈巧 ×1.5；騎士 = 力氣 + 生命力 ×1.25；僧侶 = 力氣 + 信仰 ×1.25；民兵 = 力氣 ×2。小數結果無條件捨去，再加上武器／套裝對應的直接加成。命中值固定以 95 為基礎，再加上武器與其他效果提供的直接加成，不再由靈巧換算。閃避值為 `min(35, max(0, 靈巧) ×35 // 376)`，線性成長。暴擊率使用後期增幅逐漸放緩的指數曲線：靈巧 10 時為 10%，靈巧 376 時約為 95%，上限 100%。暴擊傷害依職業為裝甲步兵 150%、騎士 125%、弓兵 175%、僧侶 125%，民兵維持 150%；數值保存於個人戰鬥快照。新建戰鬥使用目前公式。不再區分魔攻、魔防。

每點基礎能力的效果（先合計角色成長與飾品加成）：

| 能力 | 效果 |
| --- | --- |
| 生命力 | 每點最大 HP +10，另有基礎 50 HP；騎士每點另提供 1.25 攻擊，也提高騎士衝鋒與重整旗鼓的效果 |
| 力氣 | 裝甲步兵每點攻擊 +3；弓兵、騎士、僧侶每點 +1；民兵每點 +2 |
| 耐力 | 每點防禦 +3；每 10 點耐力使單次基礎傷害約少 10.5，尚未計入穩定度、暴擊、減傷與取整 |
| 靈巧 | 線性提高閃避值，並以後期漸緩曲線提高暴擊率；Lv.120 弓兵約為 35% 閃避、95% 暴擊；弓兵每點另提供 1.5 攻擊；不再提供命中 |
| 信仰 | 每點治療量 +3；僧侶每點另提供 1.25 攻擊；治療技能再依各自倍率計算 |

玩家速度採 1～100 尺度，不再隨靈巧或等級無限成長：民兵／裝甲步兵／騎士／弓兵／僧侶的基礎速度分別為 50／45／40／60／50。一般商店武器依早期、普通、老練、精銳階提供 +0／+5／+10／+15 速度；Lv.20 掠奪者與血翼系列提供 +7，Lv.30 疫骨系列提供 +8，T40 討伐武器提供 +9，避免提早追平 T50 商店武器。最終速度限制於 1～100。武器命中值按設計內容等級配置：木棒 +0、T10／T20／T30／T40／T45 武器分別 +10／+20／+30／+40／+45；商店 T50／T90 武器則為 +50／+90。同階怪物使用接近相同的閃避值，特殊怪物只在基準附近小幅增減。每回合先處理挑釁反擊、祝福、護衛與架勢這類準備型增益，再由其他行動依速度排序；同速度使用固定種子的隨機順序。治療與淨化等會依當下戰況決定價值的技能仍在一般階段，速度不增加行動次數或縮短冷卻。實際命中機率為自身命中值減去目標閃避值，最低 10% 且沒有上限；結果達 100% 以上即必定命中。命中值本身同樣沒有上限。閃避值上限為 35（裝備與補給後最高 40），暴擊率上限為 100%。

耐力防禦換算為每點 +3，既有角色與飾品自動套用；武器／套裝及護衛直接增加防禦。防禦扣傷係數依承受傷害者的職業決定：騎士 0.45、裝甲步兵 0.40，民兵、弓兵、僧侶與所有魔物維持 0.35。已開戰的討伐載入後也依目前職業係數計算後續攻擊。


核心規則與裝備目錄在 `core/rpg_character.py`。材料保存在 `rpg_inventory`，獨立裝備、染色與刺繡詞條分別保存在 `rpg_equipment_instances`、`rpg_instance_sockets`、`rpg_instance_affixes`，穿戴欄以實例編號關聯。啟動會在單一交易內自動遷移舊背包與穿戴資料，不改寫既有經驗值、文字冷卻或進行中的戰鬥快照。

獨立的 `/卸下` 指令已移除，請使用 `/冒險 → 裝備／能力` 面板內的「卸下」按鈕。

## 安安的魔物討伐

每個伺服器／討伐頻道獨立保存第三版動態難度，初始與最低為 1 倍，最高 2.5 倍。HP 完整套用難度；攻擊只套用 40% 幅度；防禦只套用 10% 幅度。公式分別為 `HP × 難度`、`攻擊 × (1 + (難度 − 1) × 0.4)`、`防禦 × (1 + (難度 − 1) × 0.1)`；例如難度 2.5 時為 HP ×2.5、攻擊 ×1.6、防禦 ×1.15。

普通怪在 7 回合前勝利使下場難度 +4%，7～13 回合 +2%，14 回合後仍增加 +1%。回合上限依削減 HP 比例使難度 −15%／−10%／−5%；戰敗則為 −25%／−20%／−15%，對應怪物削減未滿 60%、未滿 85%、至少 85%。以上皆以前一場難度相乘後限制在 1～2.5。四種品質都參與校正，但普通／精英／首領／傳說分別只套用調整量的 100%／50%／25%／10%，避免單場稀有怪過度扭曲一般場次。勝利經驗與金幣仍依動態值同比例增加，小數無條件捨去；掉落率不變。舊平衡版本保存的難度不帶入第三版，新版頻道由 1 倍重新校準；舊討伐快照仍使用舊規則且不會覆寫新版難度。

公告時固定本場難度：最終強度 = 頻道動態難度 × 管理員指定強度（預設 1），再套用血量、攻擊、防禦；公告不展示管理員強度倍率，戰報仍顯示下一場動態難度。動態上下限不限制管理員倍率造成的最終強度。普通品質的基礎勝利 XP 依怪物階層配置：0／1／2／3／4／5／6 階分別為 1,000／300／450／600／750／900／1,050 XP，再乘品質獎勵與公告時動態難度；0 階史萊姆是特殊稀有怪，因此獎勵高於一般低階怪。管理員手動強度不增加報酬，手動指定的經驗／金幣各自覆蓋為最終數額，未指定者照常縮放。報酬公告時固定，重啟與結算不重複乘算；更新前已公告的報酬保留。難度與獎勵、活動結算同一交易保存，重啟保留且重試不重複調整。更新前已公告的活動維持原強度，但更新後完成結算會調整下一場；已完成活動不追溯計算。

怪物類型機率：巨獸 25%、毒蛛 25%、史萊姆群 10%、鐵殼魔像 20%、荊棘妖樹 20%。新版史萊姆群由三隻獨立敵人組成，整群 HP 平均分配（餘數依編號分配），每隻每回合使用一次 45% 攻擊倍率的「彈跳撞擊」，各自判定命中與暴擊；優先嘲諷者，否則攻擊剩餘血量比例最低者。倒下的史萊姆停止行動，全部擊倒才算勝利。箭雨可攻擊三隻，「存活敵人 ≥ 3」條件可生效；整群共用一次獎勵結算，不按隻數倍增。舊公告與舊戰鬥仍保留共用血量、三連擊規則。

史萊姆群是特殊稀有的 0 階怪，普通品質基礎勝利經驗為每人 1,000 XP；金幣仍為一般頻道設定值的兩倍（預設 200），兩者再乘動態難度，且絕不掉落飾品。失敗或回合上限依怪物已削減 HP 比例發放該場勝利經驗與金幣，無掉落。獎勵在公告時固定，重啟與重試結算不會重複乘算。以下一般掉落規則只適用巨獸與毒蛛。

在 `.env` 的 `RPG_RAID_CHANNEL_IDS`、`RPG_MID_RAID_CHANNEL_IDS`、`RPG_HIGH_RAID_CHANNEL_IDS` 分別指定一般、中階及高階討伐文字頻道，皆支援逗號分隔多個 ID且三類不可重複；留空就不發布該類活動。每個頻道擁有獨立排程、洗牌池與動態難度，依序使用 `[rpg.raid]`、`[rpg.mid_raid]`、`[rpg.high_raid]`。若重新抽選的當下位於 `half_interval_periods` 指定的每日時段，隨機區間上下限皆減半。時段採開始時間包含、結束時間不包含；已抽出的時間不會因進出時段而變更。同一伺服器一次只開放一場一般、中階、高階或特殊討伐；多個排程同時到期時先發布原到期時間最早者，其餘保留原到期時間，等本場結束且結果送出後依序發布。排程保存在資料庫，重啟不會重新抽倒數。功能使用 Bot 自身排程，不需要 Codex 自動化。

管理員可使用 `/冒險區域` 將以上 `.env` 頻道及 `RPG_TAVERN_CHANNEL_IDS`、`RPG_ADVENTURER_ROLE_IDS` 的有效項目匯入資料庫。建立／匯入會沿用同一伺服器的既有項目，只補建缺少的「安安大冒險」分類、冒險者身分組及四個文字頻道，並替仍在伺服器內的既有 RPG 玩家補上冒險者身分組；不移動或修改既有頻道。修復才會把四個頻道移入統一分類並套用必要權限。`@everyone` 看不到冒險區域，冒險者可查看所有頻道；三個討伐頻道禁止冒險者發言，酒館允許發言、附件、反應及討論串。管理員及安安仍可發布。修復只更新 `@everyone`、冒險者與安安的必要覆寫，不刪除其他管理員自訂覆寫，也不會自動刪除任何頻道或身分組。資料庫登記優先於 `.env`，後者保留作相容備援。

管理員可在設定的討伐頻道使用 `/生成討伐`，直接生成魔物，保留五分鐘報名與正式獎勵。指令會在執行時再次確認管理員權限；活動停用、錯誤頻道或該頻道已有活動／正在生成時不能使用。手動活動結束後重新抽下一次自動出怪時間。

`/生成討伐` 支援以下選填參數，僅影響本場，未填沿用預設：

| 參數 | 用途 |
| --- | --- |
| 類型 | 一般頻道可選 0～2 階、中階頻道可選 3～4 階、高階頻道可選 5～6 階；未填依該頻道的怪物池抽取 |
| 名稱 | 1–20 字，覆蓋生成名稱 |
| 強度 | 0.1–10 倍，預設 1；開戰時計算正常血量、攻擊、防禦再乘倍率，捨去小數且最低 1 |
| 經驗 | 勝利每人最終 XP，0–100,000 |
| 金幣 | 勝利每人最終金幣，0–1,000,000 |
| 掉落率 | 飾品掉落百分比，0–100；史萊姆群強制為 0 |

例如 `/生成討伐 類型:巨獸 名稱:狂暴巨獸 強度:2 經驗:1000 金幣:300 掉落率:75`。自訂經驗、金幣直接作為最終數額；未指定的 XP 依怪物階層計算，其他獎勵沿用該類型預設。公告顯示最終獎勵但不顯示管理員強度倍率，資料隨活動保存；重啟後保持一致，不修改自動討伐設定。報名時間、失敗獎勵、行動頻率與回合上限維持原規則。

1. 安安在指定文字頻道發布一場怪物討伐及報名按鈕。模型只構思名稱與出場描述，巨獸橫掃／毒蛛中毒等戰鬥特性與數值由程式決定。預設沿用 `ai.model`、`OPENAI_API_KEY` 和 `config/persona.txt`，每次出怪最多呼叫一次 API，不傳頻道聊天、成員名單或玩家資料；超時、未設定 Key、格式錯誤時使用備用怪物描述。`ai_monsters = false` 可停用模型生成。討伐生成有獨立排程，不計入聊天功能的 AI 次數限制。
2. 成員點「參與討伐」，可在截止前退出；不能重複報名，機器人不能報名。報名固定 5 分鐘，最多 20 人，可配置人數。一般討伐 Lv.1 民兵即可參加；中階討伐需達 Lv.30；高階討伐需達 Lv.50。倒數期間可以用 `/冒險 → 裝備／能力`、`/冒險 → 技能` 調整策略。同一伺服器不會同時開放另一場討伐；程式仍保留跨場重複報名防護，以相容舊資料與異常狀態。
3. 截止時鎖定仍在伺服器的參與者、職業、能力、裝備與技能設定，再開戰。至少一人即可開始，無人則怪物離開，不發獎勵。沒有 NPC 隊友，實際報名者共同對付本場怪物（史萊姆群為三隻）。隊伍名單與數值鎖定後，換職、換裝及能力公式調整只影響下一場；已採單一攻擊／防禦的進行中戰鬥保留開戰快照。
4. 原本的討伐訊息每 5 秒更新一個回合，顯示最新 Log、魔物與隊伍 HP；完整 Log 保存於資料庫，結束時在同一則訊息附 `討伐戰報.txt`。一次斷線不會補刷大量訊息，重連／重啟後從保存的回合繼續。戰鬥最多 30 回合，全隊倒下或魔物倒下即結束。
5. 根據隊伍結果自動給所有鎖定參與者獎勵，包含戰鬥中倒下或開戰後離線的玩家。普通品質基礎 XP 依 0～6 階分別為 1,000／300／450／600／750／900／1,050，金幣依頻道設定；依品質以 12.5%／20%／30%／50% 機率從該怪物掉落表等機率抽一件，不排除已持有品項。失敗、平手或到達回合上限，按怪物結束時已削減 HP 比例發放該場勝利經驗與金幣（無條件捨去），無掉落。重複掉落累加數量，不轉換成額外 XP；目前巨獸與毒蛛不掉武器或套裝；未來怪物使用獨立掉落表。XP 直接計入角色，掉落直接放入背包，不會自動換上。

討伐專屬飾品為魔物心核、裂牙指環、岩鱗徽章、風羽吊墜、星痕念珠，分別提供一項能力 +6、其他四項各 +1。職業補給不會發放這些物品。公告時保存該場獎勵設定，之後改設定不會改掉已公告的獎勵。結算狀態、XP、金幣、掉落使用同一筆資料庫交易；重試、重啟或結果訊息傳送失敗不會重複入帳，已結算但未送達的結果會重試編輯原訊息。

`[rpg.raid]`、`[rpg.mid_raid]` 與 `[rpg.high_raid]` 可分別調整開關、隨機間隔、人數、勝利金幣與掉落機率；其中 `victory_xp` 僅保留給舊怪物快照或缺少階層資料的相容流程，新討伐 XP 使用怪物階層表。停用或移除頻道設定會取消尚在報名的活動；已開戰的活動會完成。若活動訊息被刪除，未結束的活動取消，已入帳獎勵保留。發布瞬間崩潰可能留下無效報名訊息，重啟後不會為該訊息開戰；管理員可刪除。頻道權限暫時失效時會保留狀態等待恢復。維運時只運行一個 Bot 實例。

## 金幣

金幣依伺服器與玩家獨立保存，初始為 0；`/冒險` 和 `/冒險 → 裝備／能力` 面板會顯示餘額。討伐勝利時，每位鎖定參與者（含倒下者）取得 `[rpg.raid].victory_gold` 指定的金幣，預設 100，可設為 0；失敗與平手依怪物已削減 HP 比例發金幣，取消不發獎勵。可在 `/冒險 → 商店` 購買進階武器與套裝，支援物品出售，尚無金幣轉帳功能。

餘額保存於 `data/rpg.db` 的 `rpg_wallets`，重啟保留。金幣與 XP、掉落、結算狀態共同提交，失敗一起回滾，重送戰報不重複發獎。金額在活動公告時固定，之後修改設定只影響新活動；更新前已發布且沒有金幣設定的舊活動不補發金幣，歷史獎勵不追溯補發。

## 冒險者酒館

從 `/冒險 → 移動 → 冒險者酒館` 可準備料理、張貼懸賞或公開請客。一般／中階／高階懸賞分別花費 2,000／5,000／8,000 金幣，發起者自動報名；中階需達 Lv.30，高階需達 Lv.50。懸賞討伐沿用對應頻道的基礎 XP 與掉落規則，但勝敗皆不發金幣，不套用也不調整頻道動態難度。懸賞不重新抽取正常討伐時間；若正常討伐在懸賞期間到點，會在懸賞完成並送出結果後發布。討伐頻道已有活動或結果尚未送出時不能張貼。扣款與懸賞建立使用同一筆交易；公告發布失敗或發布途中重啟會自動退費。

料理與請客公告一律發布到 `.env` 的 `RPG_TAVERN_CHANNEL_IDS`；可列出多個伺服器的頻道 ID，每個伺服器使用清單中第一個屬於自己的可用頻道，沒有設定時不會改發到操作所在頻道。米莉亞的電影同樂會為 500 金幣／5 杯、梅露露的暖心茶會為 1,000 金幣／10 杯、諾亞的豪華監獄餐會為 2,000 金幣／20 杯。飲料公告開放 2 小時，並逐杯顯示完整乾杯紀錄；每次乾杯取得一次「下一場討伐 XP +5%」，效果保留 24 小時並在下一場討伐開戰時綁定。飲料與料理分開計算，玩家可以各持有一份並在同場討伐一起生效，但不能囤積兩份飲料；飲料效果消耗後可在仍開放的同一場請客再次領取，並再次消耗一杯。酒館私人面板會分欄顯示目前飲料及料理的效果、料理剩餘場次與到期時間。請客與領取狀態保存於資料庫，重啟後按鈕仍有效；公告發布失敗或發布途中重啟會自動退費。

## 漢娜的裁縫所

從 `/冒險 → 移動 → 漢娜的裁縫所` 可使用裝備染色與飾品刺繡。染色僅適用於諾亞武器與套裝，每次消耗所選顏色噴漆罐 1 個並支付 1,000 金幣；再次染色會取代原顏色，舊顏料與費用不返還。紅、黃、藍三色沿用原有戰鬥效果。原裝備面板不再提供顏料加工。

刺繡僅適用於飾品。首次轉職免費取得的生命護符、力量指環、堅韌徽章、靈巧吊墜與信仰念珠沒有刺繡格；目前所有討伐飾品——魔物心核、裂牙指環、岩鱗徽章、風羽吊墜、星痕念珠、戰團徽章、月影墜飾與雙生護符——各有一格。愛心／火焰／盾牌／羽翼／星光刺繡分別提供生命力／力氣／耐力／靈巧／信仰 +2，每次支付 500 金幣；再次刺繡會覆蓋原圖樣。染色與刺繡皆保存於單件裝備實例，給予其他玩家後仍保留；扣款、消耗材料與加工結果使用同一筆資料庫交易，失敗時全部回滾。

## 生活技能：釣魚

## 生活技能：農耕

從 `/冒險 → 生活 → 農耕` 管理田地；開啟面板時預設選擇已解鎖的最高等級田地與作物。「中庭花圃」自農耕 Lv.1 開放，「監獄菜園」自 Lv.20 開放，「廢棄溫室」自 Lv.40 開放，「遺址種地」自 Lv.60 開放；解鎖後四地是互相獨立的田地，可以同時種植。地點本身不限制作物，玩家可在任一已解鎖的空田選擇所有已由農耕等級解鎖的植物。可單獨中斷目前選取田地的種植，中斷後不會依成長進度獲得作物或 XP。種植時固定當下農耕等級、植物及成熟時間，Bot 重啟不會遺失；成熟後需手動收成，再次操作不會重複發放。

## 酒館料理與料理等級

從 `/冒險 → 移動 → 冒險者酒館 → 準備料理` 選取正好五份食材；同一食材可重複選擇，但不能超過背包持有量。所有魚、作物、水草、藥草及討伐肉類都是一般素材，另可放入至多一份調味料。料理面板提供三格可命名的配方 preset，可保存目前選滿的五份食材，之後載入、調整或清空；載入只會填入選擇欄，不會立即消耗，素材不足時不可載入。「載入上一份配方」仍可取回最近一次成功料理或捐給監獄時使用的 1～5 份素材。完成料理會取得料理 XP；料理技能使用 RuneScape 標準經驗曲線與 Lv.120 上限，滿級後仍可累積 XP。

美味度上限為 130：基礎 30 分，每點品質 +2、每種不同素材 +4、每組推薦搭配 +8，料理等級每 10 級 +1（最多 +10），最後加上調味料的 4／8／12 分。D／C／B／A／S／SS／SSS 的門檻依序為 0／45／55／70／85／100／115；Lv.1 最高完成 S、Lv.40 解鎖 SS、Lv.80 解鎖 SSS，預覽會同時顯示潛在與完成評級。料理 XP 為品質總和 ×50，再乘 D～SSS 的 80%／100%／110%／125%／140%／160%／185%。完成時先取得 25%，其餘 75% 由前三位不同客人享用後共同解鎖。

效果標籤包含「成長、猛攻、活力、滋養、幸運」，盛宴只增加分享份數，不能獨立構成有效料理。主標籤由數量最多者決定，同數時依素材選取順序；第二多且至少出現兩次的標籤自料理 Lv.20 起成為副標籤。副效果於 Lv.20／40／60／80／100／120 分別發揮 50%／60%／70%／80%／90%／100%，並在完成料理時保存。

| 活力 | 最大 HP、治療量 +3%／+4%／+6%／+8%／+11%／+13%／+15% |

基礎效果份數為 3，每份盛宴素材 +1，五份中至少四種不同素材再 +1，上限 8；可入席人數直接等於總效果份數。稀有魚不再提供餘韻，餘韻只來自粗磨岩鹽／魔女香料／星砂香料的 +2／+3／+4，分別使每位用餐者持續 2／2／3 場，不再切分席位。料理效果與飲料效果都保留 24 小時；料理在正式開戰時消耗一場，「節制」使該場正常生效但不消耗場次。

所有新料理都能在設定的酒館公開頻道開桌 30 分鐘，基礎至少 3 席，不再因餘韻產生私人料理。同一位料理者同時只能有一桌尚未客滿且仍在公開期內的料理；料理者若沒有未用完的料理效果會自動入席，其餘成員可按「一起享用」領取。其餘 75% 料理 XP 由 `min(可入席人數 − 1, 3)` 位不同客人平均解鎖；額外席位可享用效果但不再增加 XP。飲料與料理效果分開保存，可在同場討伐一起生效。

勝利討伐另為每位參戰者獨立判定料理食材，不占裝備掉落。普通／精英／首領／傳說品質成功率為 35%／50%／75%／100%；成功後 95% 取得肉類、5% 取得調味料。0–2 階掉落鮮獸肉（盛宴 Q2）或粗磨岩鹽，3–4 階掉落魔獸里肌（盛宴 Q3）或魔女香料，5–6 階掉落星露霜肉（盛宴 Q4）或星砂香料；每場每人最多一份。

料理面板可將目前選取的一至五份料理素材捐給監獄，不發布酒館公告。捐贈 XP 以素材品質總和 ×50 的 50% 計算並無條件捨去，不套用料理評級倍率；比把相同素材做成 C 級料理時立即取得的 25% 多一倍，但沒有客人解鎖其餘經驗的機會。舊版料理與藥水庫存首次更新時會自動拆回原配方素材，舊補給配置一併清除。

## 瑪格的占卜室

從 `/冒險 → 移動 → 瑪格的占卜室` 支付金幣抽取塔羅牌。每天不限占卜次數；台灣時間每日第一次為 300 金幣，當日第 N 次為 `300 × N` 金幣。每日 00:00 只重置次數與價格，不會清除尚未使用的牌。再次占卜會覆蓋原本尚未使用的牌且不退費；效果綁定正在進行的討伐後不能再次占卜。每位玩家同時只能持有一張牌，參加的討伐完成後無論勝敗都會清空。

所有牌都會使該場最終個人討伐 XP 增加 10%（無條件捨去），不增加金幣。能力型牌在開戰時連同裝備、技能與料理寫入戰鬥快照；閃避值與暴擊率仍受既有上限限制，命中值不限。「節制」使該場料理正常生效但不消耗剩餘場次；「命運之輪」使個人裝備掉落率相對提高 40%。命運之輪與幸運料理的相對加成先相加，再乘上基礎掉落率；例如兩者各 +40% 時，12.5% 會成為 22.5%，不是 92.5%。「死神」的 5% 吸血與武器及滋養料理的吸血相加，只計直接傷害。「魔術師」使技能冷卻減少一回合，最低仍為一回合。「世界」使最大 HP、攻擊、防禦、治療量、速度、命中值、閃避值與暴擊率各增加 10%。

「戀人」在開戰時與一名尚未締結連結的隨機隊友配對，兩人平均分攤彼此受到的傷害；單人或沒有未配對隊友時不生效，但仍保留 XP 加成。直接攻擊先依原目標完成防禦與減傷，再分攤最終傷害；中毒與腐敗等固定傷害也會分攤，且不會遞迴觸發。「審判」每場第一次受到致死傷害時保留 1 HP。「隱者」首次由 40% HP 以上降至 40% 以下時，獲得至下一回合結束的 25% 直接傷害減免。

稀有的「女祭司」可由玩家確認後，立即在該伺服器發起角色有資格參加的最高階討伐並自動報名：Lv.1–29 使用一般池、Lv.30–49 使用中階池、Lv.50 以上使用高階池；不包含測試中的總力戰。對應討伐頻道必須已設定、啟用且空閒；發布失敗不消耗牌，可稍後重試。女祭司發起的討伐沿用正常怪物、品質、動態難度、獎勵與五分鐘報名規則。

## 自動技能規則

新增「隊友有可淨化負面狀態（含自己）」施放條件；淨化可選「有可淨化負面狀態的隊友」目標，僅在存活且中毒／破甲／暈眩的隊友中挑血量比例最低者。無人符合時跳過，不耗冷卻；過期狀態與已倒下隊友不列入。新預設淨化使用上述條件與目標，既有玩家已保存的設定不覆蓋。淨化原本就會篩除沒有負面狀態者，舊的「血量比例最低／攻擊最高／自己」仍可用；每回合只行動一次，若要優先淨化，請將其順位調為 1。

查看與設定已合併至 `/冒險 → 技能` 私人面板，獨立的技能設定指令已移除。先選技能，再使用下拉選單調整優先順序、施放條件與目標，或按按鈕開關自動施放；變更立即保存，下次開戰套用。固定作用於自身、全隊或全體敵人的技能會停用目標選單並標示範圍。面板可重新整理或關閉，閒置 3 分鐘逾時後重開即可。轉職後舊面板會重新載入技能，不會將舊職業的點擊操作套到新職業。


民兵包紮恢復施放者治療量的 50%（無條件捨去），僧侶治療恢復完整治療量；皆不超過目標最大 HP。

每個職業固定三個技能槽，可個別開關、設定優先順序 1–3（更改時交換順位）、條件與目標；依伺服器／玩家／職業保存，換回職業仍保留原策略。預設全部開啟，民兵也有技能。Lv.20 起四個轉職職業各解鎖兩個新技能，可從五個已解鎖技能中選三個裝備；民兵維持三個。解鎖不會自動更換既有配置。

Lv.50 晉升後，每個轉職職業另解鎖一個被動技能格及三個職業被動，三選一且可在戰鬥外自由更換。各職業的選擇獨立保存，開戰時連同主動技能鎖定；進行中的戰鬥不受之後更換影響。所有連段與層數每場從零開始並保存於戰鬥快照，重啟後不會遺失。民兵沒有職業被動；若管理員提高晉升門檻而使角色低於 Lv.50，被動暫停生效但選擇仍保留。

在 `/冒險 → 技能` 選擇技能格，按「更換技能」後選擇已解鎖技能，立即保存並返回策略設定。每個技能只能裝備一次；已在其他格的技能需先從該格替換。替換保留該格的優先順序與自動施放開關，條件及目標恢復新技能預設值，可再自行調整。舊資料自動保留原有三技能及設定；開戰時鎖定配置，戰鬥進行中更換只影響下一場。

新增【準備】技能詞條，代表技能會在一般行動前結算；多個【準備】技能之間仍按速度由高到低排序。目前帶有此詞條的是防禦、破甲、攻守架勢、挑釁反擊、護衛與祝福。其餘玩家與怪物行動再按速度排序，同值隨機，每人只行動一次。因此裝甲步兵的破甲、慢速騎士的挑釁反擊及慢速僧侶的祝福仍能在當回合其他攻擊前生效；騎士衝鋒、治療、淨化與重整旗鼓仍保留一般速度時機。自動戰鬥從優先 1 開始，選第一個開啟、冷卻結束、符合條件且有有效目標的技能，否則普攻。所有職業（含僧侶）普攻均使用攻擊，各職業攻擊分別由力氣與自身特色能力換算，再加上武器／套裝的直接加成。技能冷卻 2 表示在第 1 回合使用後，第 2、3 回合不可用，第 4 回合才可再次使用。

數值條件包含「自身 HP ≤ X%」與「隊伍有人 HP ≤ X%」（X 可設 1–100）、「受傷隊友數量 ≥ X」（X 可設 1–20，包含自己）、「存活敵人數量 ≥ X」（X 可設 1–3）、「任一敵人 HP ≤ X%」與「任一敵人 HP ≥ X%」（X 可設 1–100）、「隊友疊層負面狀態 ≥ X」（X 可設 1–10），以及「戰鬥回合 ≥ X」（X 可設 1–30）。選取數值條件時會開啟輸入視窗，通過範圍驗證後才保存。其餘條件包含「可用就施放」、「隊友有可淨化負面狀態（含自己）」、「敵人正在蓄力」、「敵人有可擊破防護」、「敵人處於破甲」、「非首領敵人存活」與「機制目標出現」。

條件指向特定對象時會先限制合法目標，例如正在蓄力時的盾擊只會選擇蓄力者；找不到符合者便檢查下一個技能。史萊姆群與哥布林戰團開戰各有三隻魔物，可觸發敵人數量條件；箭雨預設為 3 隻。目標可選血量比例最低／最高、攻擊最高、首領本體優先、非首領敵人優先、機制目標優先或支援技能的自己；「優先」類目標不存在時會退回其他合法目標。

祝福預設選擇攻擊最高者。敵我由技能決定；架勢與挑釁反擊固定作用自身，護衛作用於全體存活隊員（包含自己），範圍攻擊作用全體敵人。治療跳過滿血者；聖光可選擇滿血隊友，治療量為 0 時仍會造成範圍傷害；淨化會辨識中毒、毒箭侵蝕、破甲、暈眩、虛弱、腐敗與溺印；祝福跳過效果仍存在者；護衛在有隊員尚無護衛效果或可獲得更強加成時施放。騎士衝鋒預設「可用就施放／血量比例最低的敵人」，護衛與聖光預設「隊伍有人 HP ≤ 50%」，重整旗鼓預設「自身 HP ≤ 40%」。不復活已倒下的角色。

戰鬥結算與完整戰報將輸出分為「實際傷害」與「輔助傷害」。普通攻擊及技能直接造成的最終扣血屬於實際傷害；中毒的每次實際扣血歸入施毒者的輔助傷害；祝福與破甲則以同一次攻擊在沒有該效果時的最終傷害作比較，僅將實際增加的扣血歸入效果施放者的輔助傷害。若增傷部分溢出目標剩餘 HP，不會列入輔助傷害。兩類加總等於敵人實際損失的 HP，不重複計算；舊戰鬥快照無法回推間接傷害，會將既有傷害視為實際傷害。

挑釁反擊會優先吸引單體攻擊；每次受到敵方直接攻擊且雙方仍存活時，以一般命中、暴擊、武器穩定度及防禦規則對攻擊者反擊 100%，反擊不會再次觸發反擊。騎士衝鋒以施放者最大 HP 作為攻擊基礎造成 50% 單體傷害，預設可用就施放；舊堅守的「自身 HP ≤ 40%／自己」預設會轉換為「可用就施放／血量比例最低敵人」。民兵防禦減傷 20%，裝甲步兵攻守架勢減傷 35%（並提升攻擊 20%）。破甲使目標的防禦在計算直接傷害時歸零；護衛使全體存活隊員的防禦增加施放者自身防禦的 100%（最低 +1），並在持續期間免疫及清除中毒、毒箭侵蝕、破甲、暈眩、虛弱與腐敗。多名騎士的護衛不疊加，取較強值。祝福提升攻擊 25%。這些效果持續至施放的下一回合結束。怪物毒蛛的既有中毒仍按玩家最大 HP 的 5% 結算；玩家毒箭改為保存每支箭命中時的攻擊值，於後續兩回合各自造成該攻擊值 70% 的無視防禦傷害，多支可並存並分開結算。

實際命中率為攻擊者命中值減去目標閃避值，最低 10% 且沒有上限；達 100% 以上即必定命中。同階武器與怪物的兩項數值互相抵銷，基礎命中率約為 95%。傷害為 `max(1, int(攻擊 × 技能倍率 - 防禦 × 職業係數))`；承傷者為騎士時係數 0.45、裝甲步兵 0.40，其餘玩家與魔物 0.35。之後再乘武器穩定度隨機百分比（整數均勻抽取，最低傷害 1），暴擊時乘攻擊者個別的暴擊傷害，最後套用減傷。暴擊率最高 100%。普攻及傷害技能每次命中獨立抽取；治療、中毒與毒箭侵蝕不受穩定度影響。怪物穩定度為 100–100%，玩家空手無法造成傷害。魔物 HP 為參與者各自 `150 + 等級 ×28` 的總和；攻擊為 `22 + 平均等級 ×6 + max(0, 平均等級 − 20)`，即 Lv.20 前維持原成長、Lv.21 起每級額外 +1；其餘能力亦按平均等級決定。裝備提高的能力不會提高魔物強度。

模型介接參考：[OpenAI Structured Outputs](https://developers.openai.com/api/docs/guides/structured-outputs)。戰鬥引擎、排程與結算分別位於 `core/rpg_battle.py`、`core/rpg_raids.py`、`core/rpg_raid_store.py`。

## 設定與部署

調整 `config/settings.toml` 的 `[rpg]` 後重啟生效。`enabled = false` 暫停兩種 XP，保留查詢及現有資料。所有可見文字頻道均可累積，尚未提供頻道排除清單。

沿用現有 Discord Token 與啟動方式。Developer Portal 必須啟用 Server Members Intent、Message Content Intent（現有主程式使用 `Intents.all()`）；Bot 需看得到參與的頻道，能發送訊息、嵌入連結及附加檔案，並以 `bot`、`applications.commands` scopes 安裝至伺服器。

資料自動保存至專案的 `data/rpg.db`，包含角色、裝備、技能策略、報名、魔物、戰鬥快照、戰報及獎勵紀錄，不存頻道聊天內容或音訊；此檔案已符合現有 `.gitignore`。停止 Bot 後備份資料庫；若運行中備份，需使用 SQLite backup API。不要同時啟動多個相同 Bot 實例，以免語音重複計分。此版本使用同步 SQLite 短交易，適用小型伺服器。

離線驗證：`python -m unittest discover -s tests`。實際部署後，以兩位真人驗證文字冷卻、語音一分鐘後加分、單人／靜音不加分，以及重啟後角色資料保留。

語音狀態與事件依據：[discord.py API 文件](https://discordpy.readthedocs.io/en/stable/api.html#discord.on_voice_state_update)。

掉落表位於 `core/rpg_raid_store.py` 的 `DROP_TABLES`：現有五種討伐飾品只綁定巨獸與毒蛛，史萊姆群為空表。新類型未設定時不掉裝備，不會繼承現有飾品；未來可明確列入該類型的飾品、套裝或武器 ID。每場公告時保存掉落表與機率，之後修改不影響已公告活動；舊活動無掉落表快照時依類型對應，不向新類型提供通用掉落。重複裝備會建立不同實例，材料與消耗品才累加數量。新活動依品質決定掉落率（普通 12.5%、精英 20%、首領 30%、傳說 50%），管理員可用掉落率參數覆蓋，但不能讓沒有掉落表的類型獲得物品。

## 討伐通知身分組

Bot 需要管理身分組權限，且最高身分組位置高於通知組。一般、中階與高階討伐分別使用「安安大冒險・討伐通知」、「安安大冒險・中階討伐通知」與「安安大冒險・高階討伐通知」；`/討伐通知` 可分別領取、取消或一次操作全部。新活動只標記對應身分組（自動與管理員生成皆適用），允許提及僅限該組，不標記 everyone 或個別玩家；倒數、Log、結算的訊息編輯不重複通知。實際推播仍受成員個人 Discord 通知設定影響。

## 三階怪物與 T30 掉落

三種三階怪只由中階討伐發布，角色需達 Lv.30 才能報名。三階普通品質基礎勝利獎勵為每人 600 XP／200 金幣，再乘品質及該中階頻道的動態難度；四階普通品質基礎 XP 則為 750。裝備掉落率仍依普通 12.5%、精英 20%、首領 30%、傳說 50%。每場勝利全隊另固定掉落該怪物對應的一罐噴漆，從所有鎖定參戰者中隨機選一人取得，陣亡不會失去抽選資格；噴漆不占用個人裝備抽選。失敗、平手與回合上限不掉裝備或噴漆。三色噴漆可給予、不可出售，目前只作為未來內容的製作材料，尚未開放組合或消耗。

### 深淵鐘龍

第 3 回合使用「終末鳴鐘」，獲得 `max(2, 存活玩家數 + 存活玩家數 // 3)` 層鐘甲，下一回合行動時結算。玩家每次直接命中削減 1 層，暴擊削減 2 層；中毒與毒箭侵蝕等間接傷害不削減。鐘龍免疫暈眩，盾擊只按普通直接命中削減 1 層，不能直接打斷。

結算時鐘甲歸零則終末鐘聲取消，鐘龍遭到破甲、防禦歸零至下一回合結束；仍有鐘甲則對全體施放 `90% + 剩餘層數 ×15%` 傷害，最高 300%。半血以下進入第二階段，後續每次鐘甲額外 +2 層，完成一次結算後隔兩回合再次蓄力；第一階段則隔三回合再次蓄力。「敵人正在蓄力」條件可辨識終末鳴鐘。

勝利時全隊固定掉落一罐紅色噴漆罐並隨機給一名參戰者；每人另依品質機率等機率抽取四職業 T30 套裝之一。套裝每次受到直接傷害時有 5% 機率使該次最終傷害降低 50%，在其他減傷之後結算，最低傷害 1；不影響中毒或腐敗爆裂。

### 王城傀儡師

傀儡師、劍傀儡與咒傀儡分別持有整場總 HP 的 50%／25%／25%。劍傀儡存活時持續嘲諷單體攻擊並具有嘲諷的 15% 減傷，每偶數回合以 55% 傷害旋刃攻擊全隊；咒傀儡存活時使傀儡師受到的最終傷害降低 50%，每三回合對攻擊最高玩家造成 80% 傷害並破甲，可淨化。

傀儡師每三回合以「重編絲線」取代攻擊：一具死亡時以 30% HP 復活；全存活時治療 HP 比例最低傀儡 15%；兩具皆死亡時重編失敗，自身遭到破甲、防禦歸零至下一回合結束。首次降至半血時以「最後謝幕」吸收存活傀儡並停止重編：吸收劍傀儡永久攻擊 +25%，吸收咒傀儡永久獲得 20% 吸血。第二階段每三回合使用 90% 全體傷害的「王城謝幕」，每吸收一具再增加 25%。本體倒下時剩餘傀儡一同倒下。

勝利時全隊固定掉落一罐黃色噴漆罐並隨機給一名參戰者；每人另依品質機率掉落雙生護符。雙生護符需 Lv.30，五項基礎能力各 +2；佩戴者由技能或吸血實際恢復 HP 時，額外治療 HP 比例最低的另一名存活隊友相當於本次實際治療量的 10%，無條件捨去。滋養料理提供的直接傷害吸血會觸發；額外治療不會再次觸發雙生護符或共享血肉。

### 瘟疫縫合獸

普通攻擊命中後施加 1 層腐敗，最多 3 層；每三回合使用「瘟疫脈衝」取代攻擊，使全體玩家增加 1 層。玩家行動前若有 3 層便爆裂：本人損失最大 HP 的 12%，其他存活隊友各損失 3%，縫合獸因逆流損失自身最大 HP 的 1.5%，之後腐敗歸零。腐敗可被淨化；淨化會優先選擇腐敗層數最高者，同層時選 HP 比例最低者。

腐敗玩家受到技能或吸血的實際治療時，縫合獸以「共享血肉」恢復該次治療量的 20%；滋養料理提供的直接傷害吸血也會觸發。半血以下進入第二階段，脈衝改為每兩回合、共享血肉提高至 30%，腐敗逆流提高至縫合獸最大 HP 的 2%。

勝利時全隊固定掉落一罐藍色噴漆罐並隨機給一名參戰者；每人另依品質機率等機率抽取四職業 T30 武器之一。武器每次直接命中有 5% 機率使目標受到的直接傷害增加 10% 至下一回合結束；觸發該效果的命中本身不增傷，多段攻擊每段獨立判定，易傷不疊加但可刷新，不增加中毒或腐敗逆流傷害。

## 四階怪物與 T40 掉落

赤雷與蒼炎及吞城鯨屬於中階池的常駐四階怪，以 Lv.40 與 T40 裝備為設計基準，會正常抽取品質並套用中階頻道動態難度。兩者各掉落兩個職業的 T40 武器、套裝及一件專屬飾品；每位勝利玩家依品質掉落率從對應五件物品中等機率抽取一件。完整 T40 武器與套裝約提供 Lv.40 裸身角色 25% 的相關戰鬥數值，並全面高於對應的 T30 裝備；所有 T40 掉落價值 1,000、收購價 200，可給予他人。

### 赤雷與蒼炎

兩隻雙生獸各持有總 HP 的 50%。赤雷只在奇數回合行動，以普通倍率單體攻擊並受挑釁反擊影響；蒼炎只在偶數回合行動，通常對全體造成 65% 傷害，第 4、8、12、16……回合則改為對全體造成 120% 傷害的「雷炎吐息」。不符合自身奇偶數的回合不行動。

任一隻倒下時，另一隻進入「孤獸暴走」，攻擊提高 25%、速度提高 15，並開始兩回合的「再生共鳴」。倒數完成時，倒下者以最大 HP 的 20% 復活，存活者恢復原本攻擊與速度。共鳴期間視為敵人正在蓄力；盾擊命中可使該次復活延後一回合，每次共鳴最多延後一次。若另一隻也在復活前倒下則討伐勝利；復活次數沒有上限。倒數、是否延後及暴走前能力均保存於戰鬥快照。

掉落為裝甲步兵的雷牙戰斧／雙極戰甲、弓兵的蒼焰長弓／炎翎獵裝，以及雙生獸飾品。雙生獸飾品在奇數回合使單體直接攻擊的攻擊力提高 10%，偶數回合使群體直接攻擊的攻擊力提高 10%；多段單體攻擊每段皆適用，群體技能對每個目標皆適用，不強化治療與間接傷害。

### 吞城鯨

開戰時吞城鯨取得 `min(10, 3 + 參戰人數 // 3)` 層「城塞鯨脂」，有剩餘層數時受到的最終傷害降低 35%。倍率至少 150% 的單體直接攻擊、暴擊，或以至少自身攻擊 150% 的其他數值發動的單體攻擊可削減一層；群體攻擊不能削減。最後一層被擊破後不再恢復，吞城鯨遭到破甲兩回合。

吞城鯨每次行動前使水位永久增加 10，最高 100。水位 30 時「淹沒街道」使後續巨浪擺尾傷害提高 15%；水位 50 時全隊速度永久降低 10；水位 70 時全隊受到的治療永久降低 25%。水位首次達 100 時蓄力「吞城」，下一次行動對全體造成 200% 傷害；水位不會清空，施放後每三回合再次蓄力。盾擊可打斷吞城、使吞城鯨破甲一回合，並將下次蓄力延後三回合。非吞城回合中，奇數回合以「傾城撞擊」造成 130% 單體傷害，偶數回合以「巨浪擺尾」造成 60% 全體傷害。

掉落為騎士的鯨骨劍盾／吞潮重鎧、僧侶的潮鳴權杖／深海僧袍，以及吞城鯨飾品。佩戴吞城鯨飾品受到直接攻擊時，會以相同條件分別計算防禦為零及套用自身防禦的傷害，將兩者差值保存為攻擊力；新的受擊會覆蓋尚未使用的數值。下一次直接攻擊把保存值加到該次第一段／第一個目標的攻擊力，無論命中與否皆立即消耗；護衛、架勢及百分比減傷不算作防禦擋下的傷害。

## 五、六階討伐與套裝

五階與六階只會在高階討伐頻道出現，皆可由 Lv.50 角色報名；這只是入場門檻。五階怪物與裝備以 Lv.50 校準，六階怪物、六階裝備及循環徽記仍以 Lv.60 校準並要求 Lv.60 才能穿戴。正確設定自動戰鬥條件與目標的普通品質隊伍，以約 20 回合、約 35% 勝率為調校目標；完整武器與套裝約提供同階裸身角色 30% 的相關戰鬥數值。

五階包含熔爐鎧獸與迷霧菌后。熔爐鎧獸以三層爐甲減傷，高倍率單體攻擊或暴擊可逐層擊破；每四回合蓄力熔爐爆發，盾擊或擊破最後一層可打斷。迷霧菌后與兩隻爆裂孢子以 60%／20%／20% 分配 HP；孢子每三回合蓄力，未優先清除便爆裂並附加中毒，菌后則會週期治療。

六階包含星蝕巨神與逆潮聖骸。星蝕核心存活時使巨神減傷 20%；擊破核心會取消蓄力並使巨神破甲，但核心之後可重建。逆潮聖骸的攻擊會疊加可淨化溺印，每層於回合結束造成 2% 最大 HP 傷害；週期出現的逆潮法陣若未擊破，會造成全體傷害並治療聖骸。

每隻五、六階怪物各掉落對應兩職業的武器與套裝；同組武器及套裝同時穿戴後啟動 2 件效果。熔脈／星鑄套將裝甲步兵武器最低穩定度提高 15／25；爐心／逆潮套使騎士最大 HP 提高 5%／7%；孢影／星獵套使弓兵命中與暴擊分別提高 5、3／8、5 個百分點；霧祈／聖潮套使僧侶攻擊與治療提高 4%／6%。裝備面板會顯示目前為 1/2 或已啟動的 2/2。

兩隻六階怪物的掉落池另含通用 Lv.60 飾品「循環徽記」：五項基礎能力各 +3，並有一個刺繡槽；每場戰鬥第一次成功施放基礎冷卻至少 2 回合的主動技能時，使該次冷卻減少 1，最低仍為 1。


## 怪物階、品質與基礎屬性

新生成的自動／手動討伐皆獨立抽取品質，機率與數值集中於 `core/rpg_monsters.py`。0 階為史萊姆群；一階為巨獸、毒蛛；二階為鐵殼魔像、荊棘妖樹、哥布林戰團、月影妖狐、血翼蝠王；三階為深淵鐘龍、王城傀儡師、瘟疫縫合獸；四階為赤雷與蒼炎、吞城鯨；五階為熔爐鎧獸、迷霧菌后；六階為星蝕巨神、逆潮聖骸。城崎諾亞同屬四階，但為固定 T45 強度的特殊召喚戰；使用道具召喚時會像酒館懸賞一樣保留正常中階討伐排程，若排程在召喚戰期間到期，會在召喚戰完成並送出結果後發布。0～2 階只在一般頻道、3～4 階只在中階頻道、5～6 階只在高階頻道自動出現；三者使用獨立排程、洗牌池、獎勵與頻道動態難度，但同一伺服器仍依到期順序逐場開放。

## 總力戰引擎（測試階段）

`core/rpg_total_battle.py` 是獨立於自動討伐排程的手動回合引擎。每場支援 1～6 名玩家；規劃階段每名存活玩家可選擇普通攻擊或一個已裝備技能，再指定有效目標。所有人提交後先結算準備型增益，再依速度統一結算其餘行動；重複提交會覆蓋自己的舊選擇。逾時由服務層呼叫 `fill_defaults()`，將未選擇者改為攻擊最低血量比例的敵人。原目標在行動前倒下時，單體行動會自動改選同陣營血量比例最低的有效目標。

測試怪物「訓練用假人」會預告並固定循環四種行動：100% 單體標準打擊、整回合 35% 減傷的防禦校準、65% 全體廣域震波，以及對攻擊最高玩家的 180% 過載重擊。戰鬥、尚未提交的選擇與隨機狀態皆可序列化，供之後的 Discord 互動層在重啟後恢復。

管理員可用 `/開始總力戰` 建立測試房。需先在 `.env` 的 `RPG_TOTAL_RAID_CATEGORY_IDS` 填入允許建立暫時頻道的 Discord 類別 ID；若同一伺服器設定多個符合類別，使用 ID 最小者。頻道依 `總力戰-(Boss名)-(編號)` 命名，房主自動加入並可自行決定開始時機。其他玩家透過公開大廳加入／退出；開戰後點擊公開按鈕開啟自己的私人行動與目標面板。公開訊息依序顯示 Boss 血條、HP 與 Buff／Debuff、Boss 行動預告、隊伍 HP 與 Buff／Debuff、上一回合完整摘要及倒數，不公開實際選擇。回合摘要按完整行拆成數個 Discord 欄位，不會再從累積紀錄尾端截字。私人面板會列出三個已裝備技能目前可用或尚餘幾回合冷卻；完成登記的確認訊息會在 8 秒後自動刪除。

測試版每回合預設 60 秒，全部存活玩家完成選擇時立即結算；設定於 `[rpg.total_raid]`。目前不消耗入場道具、不發放獎勵，結束後頻道會保留供檢查戰報，尚未啟用自動刪除。

一般池類型機率為史萊姆群 5%；一階巨獸、毒蛛各 20%；二階五種各 11%。中階與高階池各自使用可跨重啟保存的洗牌袋，每輪讓池內所有怪物各出現一次，順序隨機；發布失敗會把該怪物放回原池。管理員在一般／中階／高階頻道分別只能指定 0～2／3～4／5～6 階。階只作內部分類，不放入名稱；普通直接顯示原名，其他顯示「精英・名稱」「首領・名稱」「傳說・名稱」。

第三版起先以 `內容等級 = 階級 × 10 + 品質等級加成` 求出錨點；零階暫時維持原公式。每位參戰者提供的原始 HP 預算為 `100 + 內容等級 × 19`，乘怪物階與類型倍率後再乘參戰人數，因此 1～20 人皆為嚴格線性。攻擊為 `int((22 + 內容等級 × 6 + max(0, 內容等級 − 20)) × 1.1)`，防禦為 `int(10 + 內容等級 × 2)`；速度直接使用上表固定值。怪物不再追隨參戰者平均等級柔性成長：高等玩家回頭打一階會確實變強；人數只增加 HP，不增加單次攻擊。動態難度與管理員指定強度最後套用。治療量仍為 0，穩定度仍為 100–100%。史萊姆、哥布林戰團與傀儡師的 HP 倍率指整群總量；傀儡師本體／劍傀儡／咒傀儡分配 50%／25%／25%。高防禦怪的 HP 特性倍率會連同實際減傷一起校準，不另外免費增加生存預算；低防但高閃避的毒蛛則以較高 HP 補足迴避以外的耐久。基準模擬會用與「階級＋品質」等效等級的玩家、對應階裝備、預設技能與無消耗品；V6 普通平衡隊的勝利場平均約 14.8～15.8 回合、勝率約 80%。可用 `python -m scripts.rpg_balance --seeds 1000 --composition balanced`，或將配隊改為 `infantry_dps`、`archer_dps`、`mixed_dps`、`no_healer`、`no_knight`、`double_monk` 檢查職業與配隊差異。

品質獎勵倍率與動態難度疊加；史萊姆群採 0 階 1,000 XP 基礎值、保留雙倍金幣且不掉裝備。每位玩家獨立抽一次掉落，不保證傳說掉裝。管理員指定的 XP／金幣／掉落率為最終數值，不再乘品質或難度；空掉落表仍不掉裝備。失敗 XP 與金幣依包含品質、動態難度及管理員覆蓋值的該場最終勝利獎勵折算。新場次的品質掉落率取代設定檔的通用 `drop_chance`，後者保留作舊制相容用途。

類型數值、品質、獎勵與掉落表在公告時保存，重啟不重抽。已公告的舊場次使用舊規則；已開戰的場次沿用戰鬥快照。

失敗獎勵公式：`每人獎勵 = 該場勝利獎勵 × (怪物最大 HP 總和 − 結束時剩餘 HP 總和) // 怪物最大 HP 總和`，經驗與金幣分別取整。包含已倒下的怪物，多隻以 HP 加權合計；怪物回血會降低最終獎勵比例，不以累積傷害計算。完全未削減血量得 0，無固定保底；例：勝利 300 XP／100 金幣，怪物剩 30% HP，失敗每人得 210 XP／70 金幣。所有鎖定參與者同額領取，失敗不掉物品。新的結算規則適用尚未結算場次，已完成獎勵不追溯；`defeat_xp` 保留作設定相容，但不再用於結算。
