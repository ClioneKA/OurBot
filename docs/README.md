## 歷史與生成報告

- `docs/balance/`、`docs/witch-*.md`、`docs/witch-*.json` 與其他 `*.json` 是本機模擬、校準或驗證輸出，供重現與回歸比較，不是正式規格，其中部分刻意不納入 Git。
- 對應的重現指令通常記在報告末尾或 `scripts/` 內；歷史報告的數字不代表目前正式數值。

## 維護規則

1. 新功能先在文件開頭標示「提案」、「實作中」、「已實作」或「歷史報告」。
2. 正式行為改動時，同步更新 `config/RPG.md` 與對應功能文件；純模擬結果另存報告，不混入部署說明。
3. 數值應指出來源程式、設定欄位或重現指令。若文件與程式衝突，以目前程式、設定及測試為準，再補修文件。
4. JSON 報告由腳本重新產生，避免手動修改大型輸出。
