# 安安大冒險：物品分類與排序

以下整理玩家能操作的物品列表。分類只改變顯示範圍；排序只改變顯示次序，均不改動背包資料或交易內容。

| 頁面 | 分類／篩選 | 排序 | 預設 |
| --- | --- | --- | --- |
| 背包 | 全部、裝備、料理素材、製作材料、換金道具、釣竿 | 分類／名稱、名稱正／反序、T 階高／低、數量多／少 | 分類／名稱 |
| 給予與出售 | 與背包相同，另依可給予或可出售條件排除物品 | 沿用背包資料的分類／名稱順序；無獨立排序控制 | 全部 |
| 顏料結晶 | 全部、輪廓、色彩、源色 | 品質、最新、最舊、詞條 | 全部／品質 |
| 人偶燃料 | 僅可轉換的背包物品 | 素材 T 階高／低、單個燃料高／低 | 素材 T 階高到低 |
| 商店 | 金幣商店、討伐之證兌換；金幣商品依當前職業篩選 | 固定商品清單順序 | 金幣商店 |
| 展示品 | 全部持有物品 | 沿用背包資料的分類／名稱順序 | 第一頁 |
| 使用道具 | 僅可使用的道具與可組合配方 | 固定操作順序 | 配方操作 |

背包的 T 階使用裝備標示的 T 階，以及可辨識製作素材的 T 階；沒有 T 階的物品排在該排序最後。同值時依名稱與實例編號排列。更換分類或排序會回到第一頁，分類與排序只作用於目前背包面板。

物品類別來自物品定義。背包「全部」會列出所有持有物品，包括舊版料理、藥水等不再單獨提供篩選的類別；給予與出售同樣沿用這組分類。顏料結晶有獨立清單，沒有混入一般背包。
