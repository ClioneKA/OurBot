# 訓練假人

使用 `/冒險` → **訓練假人**，選擇回合數（5／10／20／30）、假人數量（1／3）與防禦（0／100／300／1000），再按「開始測試／重新測試」。

每次測試讀取目前裝備、技能條件、普攻目標與職業被動，沿用討伐的角色建構與戰鬥引擎，包含套裝、刺繡、水晶和裝備特殊效果。可先到「出戰配置」套用其他配置，再回來比較相同設定下的總傷害、平均每回合傷害、命中、暴擊及技能次數。完整逐回合紀錄可下載為文字檔。

假人不反擊，閃避為 0，受到傷害後立即回滿且不會被擊倒；第一隻視為首領，其他視為非首領。破甲、毒箭等狀態仍依正常回合規則運作。這是輸出測試：低血量、受擊、擊倒敵人或隊友相關效果未必能觸發，不能用來衡量實戰生存能力。

測試固定使用亂數種子 1，相同配置及設定可重現結果；不同技能組合的亂數消耗仍可能不同。結果以每回合傷害計算，並非每秒傷害，也不等於實際討伐輸出。

訓練不消耗料理、藥水或其他道具，不發放金幣、經驗或戰利品，也不套用酒館料理與占卜效果。不建立討伐紀錄或占用討伐名額。面板僅本人可操作，180 秒無操作後逾時。
