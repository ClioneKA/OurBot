# 繪境迷宮

一般入口已開放（`ENTRY_ENABLED = True`）：可從背包使用入場畫作建立房間，
加入隊伍並開始探索。管理員仍可透過指令建立無獎勵測試場。

機器人啟動後會將已登記的入口頻道改名為 `🎨・繪境迷宮`，沿用原頻道與內容。
入口頻道允許冒險者發送訊息及使用應用程式指令；啟動時也會更新既有頻道的這兩項權限。
若改名失敗，可在確認管理頻道權限後，透過冒險區域的「建立／匯入」或「修復」重試。

## 定位

獨立於總力戰的 1～8 人 Rogue 王連戰：三幅畫作加一場尾王，全程自動戰鬥。玩家在專用的
`🎨・繪境迷宮` 頻道使用一張畫作開房；系統建立不可邀請外人的私人討論串。
探索期限為 24 小時；房間結束後，私人討論串再保留 24 小時供隊員聊天，
到期才鎖定並封存，原隊員仍可查看。關閉時間會顯示在結果面板，機器人重啟後會接續處理。
管理員可強制結束探索，討論串同樣保留一天。

入場最低 Lv.50。開房時不消耗畫作，房主正式開始且隊伍快照成功後才消耗。
料理、飲料與塔羅在開始時鎖定，效果沿用整場。
管理員測試用的 `/開啟繪境迷宮` 不檢查也不消耗入場畫作，且全程沒有任何獎勵：
不發放幕間／尾王的經驗、金幣、結晶、裝備或自選箱，也不計入諾亞首次通關。
此限制依房間的管理員測試標記判定，既有測試房的未發獎勵及重啟補發也適用。

## 流程

- 三幕各隨機抽一幅畫作，共三戰；加上尾王合計四場。既有九戰房間維持原先保存的路線，不重抽或跳關。
- 每次按下下一場只開始戰鬥，約每 2 秒更新一回合，最多 40 回合；過程寫入資料庫，重啟後續跑。
- 三幕參考強度依序為 T55、T60、T65，兩條尾王路線均為 T70。
  多體、全體攻擊及追加攻擊依各機制分配傷害，不共用同一個每次攻擊倍率。
- 每幕完成後進行 60 秒色彩契約投票；先抽三種不同顏色，再從每色三種正面效果中各抽一種，共三個候選。
  已開啟的投票保留原候選，下一次投票才採新抽法。三份契約（含第三份）的反噬都套用於尾王，
  同色按層數累加；戰前面板逐份列出反噬，實際觸發仍依命中、回合或轉階段條件。
  每次全隊獲得一份契約，平票以房間種子決定。同色三種契約共用反噬，按顏色累積反噬層數。
- 契約同時強化隊伍，並把相應色彩能力交給最終敵人；可重複選色疊層。
- 三戰完成後，依入場畫作挑戰「繪畫魔女．城崎諾亞」或「繪畫之影」。
- 探索途中只更新同一則操作面板，顯示隊員 HP、契約與掉落，不逐戰發送戰報。
  各場完整記錄先保存至資料庫；通關、失敗、撤退、逾期或管理員結束時，才發送一則整趟摘要與文字附件。
- 每場戰鬥前（包含第一戰及尾王）提供休息點，可更換已解鎖主動／被動技能，調整優先順序、開關、施放條件與目標。
  設定只保存到本房間，不改寫平常的技能配置。職業、裝備、等級與攜帶效果沿用入場快照，不會重新讀取背包或其他面板的變更。
  每名隊員都須確認準備；技能變更會取消該隊員的準備狀態，全員就緒後才能開始本場。開戰後與契約投票期間均不能修改。
- 休息點技能依優先 1～3 排序，戰前面板顯示下一場怪物特性，供調整技能時參考。
- 第三份契約確定後，先開啟 60 秒去留投票；截止前可修改，超過全隊半數同意才進入尾王休息點。
  投票通過後可調整技能，全員重新確認準備，再按「開始尾王戰鬥」開打。
  平票、棄權造成同意不足或全員未投票，一律撤退並保留全部累積掉落。
- 新房間的幕間結晶、金幣與經驗暫存到離場才發放。進入尾王後戰敗、平手、逾期或管理員結束，
  本場三類累積掉落均減半；結晶保留數向上取整（3 顆保留 2 顆，種類依房間種子決定），
  金幣與經驗按個人加成後的累積總額除以二、向下取整。沒有尾王勝利獎勵。
  開打尾王前結束不扣減。舊版房間已發出的獎勵不追扣。

## 入場畫作與最終獎勵

- `未完成的魔女畫作`：諾亞路線。首次擊敗尾王取得本職 T60 菁英裝備自選箱，
  從背包使用後選擇武器或套裝；後續通關隨機取得其中一件；
  每件裝備有輪廓、色彩、源色各一格。
- `《氣球》的畫作`：繪畫之影路線。第三幕後改打繪畫之影，不掉裝備；
  勝利時每人額外取得三顆隨機顏料結晶。
- 《氣球》的畫作在商店以 30 個討伐之證兌換。
- 一般／中階／高階討伐勝利每人分別掉落 1／3／5 個討伐之證；
  特殊召喚與管理員生成戰不掉落。

## 幕間獎勵

| 封存點 | 結晶 | 經驗 | 金幣 |
| --- | --- | ---: | ---: |
| 第一幕 | 輪廓顏料結晶 ×1 | 250 | 150 |
| 第二幕 | 色彩顏料結晶 ×1 | 400 | 250 |
| 第三幕 | 源色顏料結晶 ×1 | 600 | 350 |
| 尾王 | 路線獎勵 | 800 | 500 |

輪廓結晶提供基本戰鬥值；色彩結晶提供通用戰鬥詞條；源色結晶提供職業限定的
被動／疊層玩法。未鑲嵌結晶可交易或出售，免費鑲嵌；替換會摧毀舊結晶。
非純數值的同名唯一效果不能在已穿戴裝備上重複生效。
查看、鑲嵌、替換、出售與給予結晶均由 `/冒險` → 移動 → 漢娜的裁縫所辦理，
不另外提供玩家斜線指令。
進入「顏料結晶」後，先選裝備查看各槽位，再選相容的未鑲嵌結晶。
空槽可直接鑲嵌，已有結晶則顯示新舊效果比較並確認替換，不另提供拆除操作。
裝備與結晶可各自翻頁；加工後保留所選裝備，方便繼續處理其他槽位。
結晶一覽、出售與給予仍可從頁面上方切換。

所有幕間與尾王獎勵都使用資料庫封存點與可重試 outbox：新房間的幕間 outbox 等離場後才執行。
若程序在結算或發獎途中中斷，重啟會依已確定的保留比例補發；唯一索引保證重試不會重複發獎。

## 尾王

尾王與前三幕使用同一套自動戰鬥引擎，依休息點保存的技能策略行動，約每 2 秒更新一回合。
兩條路線均使用 T70 參考值；最多 40 回合，平手或達回合上限視為未通關。

諾亞保留自動戰鬥的 70%／35% HP 三階段、階段淨化、未乾色塊與最終蓄力技。
繪畫之影循環使用三次契約的顏色技能。六色反噬包括累積命中反擊、轉階段護盾、
加速／提早蓄力、週期回復、腐敗，以及增傷／每五回合追加行動。
不提供逐回合行動選單、手動防守或手動錨點破解；應對機制須在戰前設定技能策略。

18 種契約保留原 ID，相同顏色共用反噬並按顏色疊層。第一種保留基本效果；第二種改為技能連動，第三種是額外被動，不占職業被動槽。

| 顏色 | 第二種：技能連動 | 第三種：額外被動 |
| --- | --- | --- |
| 緋紅 | **銳筆**：交替使用不同傷害技能，第三段技能直接傷害 +60%／層；重複技能重置連段 | **點睛**：每累積四次有效直接命中，追加 90%／層威力追擊；追擊不再觸發契約連鎖 |
| 蒼藍 | **厚塗**：使用非傷害技能後獲得最大 HP 6%／層護盾；同類護盾不累加 | **留白**：每戰一次，存活時 HP 首次降至 35% 以下，獲得最大 HP 18%／層護盾 |
| 金黃 | **聚光**：普攻有效命中後，最長冷卻技能縮短 1 回合／層；每 8 回合最多一次，不立即追加行動 | **掠影**：每三回合最多一次，減輕下一次直接傷害 35%／層（最多 70%） |
| 翠綠 | **回春**：接受有效技能治療後，下次有效直接命中吸血 18%／層；最多恢復自身 10% HP，不觸發連鎖 | **庇蔭**：每三回合，各存活隊員自動治療血量比例最低的受傷隊友，回復目標最大 HP 4%／層 |
| 紫蝕 | **蝕刻**：命中帶有至少兩種負面狀態的敵人，追加 100%／層威力侵蝕追擊；每兩回合最多一次 | **洞察**：每四回合首次有效命中附加虛弱至下一回合結束；每多一層間隔 -1，最短兩回合，遵守免疫 |
| 漆黑 | **毀形**：傷害技能消耗自身最大 HP 3%／層，技能直接傷害 +32%／層；擊倒敵人回復 6%／層 HP，每技能最多一次；HP 不足不發動 | **孤注**：受到直接傷害 +4%／層；每人每戰一次，致命直接傷害保留 1 HP，至下一回合結束直接傷害 +15%／層、受治療倍率歸零；持續傷害不觸發 |

所有觸發計數、冷卻與每戰一次標記均隨戰鬥保存；追擊不再觸發契約追擊，吸血不再取得回春效果。護盾與治療不復活倒下成員。

原始選項的特殊效果保留：侵染延長中毒、毒箭、虛弱，但不延長暈眩與破甲；疾筆需至少一份，搭配任意金黃契約湊兩層才減冷卻。

翠綠反噬調整為每三回合回復尾王最大 HP 的 0.5%／層；繪畫之影的翠綠回影另回復 0.5%。同色各選項仍承擔相同反噬。

比較方式：--compare-contracts 固定前兩份為不含受測顏色的背景契約，同色三種使用相同技能配置與種子。緋紅採步兵交替技能、紫蝕採弓兵毒箭／虛弱，翠綠採僧侶群體治療／聖光；不改等級或裝備。其餘顏色沿用固定配置。

比較中的選項是強制套用，不受當場候選限制，用途是檢查同色差異與觸發次數，不是一般玩家通關率。不同顏色的背景及技能配置不同，不能直接跨色比較。

```powershell
python scripts/simulate_painted_maze.py --compare-contracts --seeds 100 --seed-start 55000
```

| 蒼藍 | 60%／29% | 57%／28% | 60%／23% |
| 金黃 | 70%／40% | 82%／39% | 73%／26% |
| 翠綠 | 25%／40% | 24%／35% | 31%／37% |

連動契約確實需要搭配技能；只使用單一傷害技能時銳筆不易觸發，未配置負面狀態時蝕刻也沒有收益。
翠綠配合蒼藍仍容易缺乏輸出，漆黑三種在兩條路線的優劣也不同；不能把一次受控比較視為全面等強或最佳解。
此輪將聚光限制為每八回合一次，孤注加入承傷／受治療代價，並降低翠綠回血反噬，避免單一選項或回血循環壓倒其他選擇。

## 平衡驗收

### Lv.60 滿裝單場基準（2026-09-09）

主要驗收為 8 人四職各二，Lv.60、T60 討伐武器／套裝與四件飾品含刺繡。
各職均佩戴循環徽記、戰團徽章、雙生護符；第四格弓兵佩戴雙生獸飾品，其他職業佩戴吞城鯨飾品。
刺繡選本職屬性（步兵力量、騎士耐力、弓兵靈巧、僧侶信仰），不使用食物、飲料、塔羅或迷宮結晶。

**勝率以各場獨立挑戰次數為分母。** 每場均以滿血開戰，不篩選前一場勝者，也不帶入前一場殘血。
第一／二／三幕分別有 0／1／2 份契約，尾王有 3 份；契約只從當場三個候選選取，
優先不同色，再依腳本攻守平衡優先序選擇。兩條尾王路線均各自跑完所有種子。
實際遊戲仍按原有幕間回復規則延續血量；這份單場基準不代表整趟通關率。

新版契約校準使用種子 0～299、60000～64999；最後驗證使用 65000～65999，每場各 1,000 次。
本表使用固定技能配置、實際抽出的契約候選；抽樣與休息點的技能策略會造成勝率差異。

| 場次 | 目標 | 獨立驗證勝率 |
| --- | ---: | ---: |
| 第一幕 | 95% | 95.2% |
| 第二幕 | 75% | 78.1% |
| 第三幕 | 60% | 57.4% |
| 繪畫之影 | 50% | 47.2% |
| 諾亞 | 30% | 29.5% |

重現單場驗證：

```powershell
python scripts/simulate_painted_maze.py --independent --accessories --seeds 1000 --seed-start 65000
```

`--benchmark` 仍可觀察血量延續、前置失敗即停止的整趟表現，但不再用於上述目標驗收。

### 契約組合壓力測試

執行：

```powershell
python scripts/simulate_painted_maze.py --seeds 20 --gear raid
```

矩陣會使用真實角色快照跑完整三戰與尾王，涵蓋 Lv.50／60／75／80、1／4／8 人、
兩條路線、六種單色三疊與代表性的雙色／三色契約。Lv.50 使用現有 T50 討伐裝；
Lv.60 以上預設使用現有 T60 討伐裝測試首次攻略。改用 `--gear maze` 可觀察本模式
T60 菁英裝延用到 Lv.75～80 的表現。
此矩陣未裝飾品，並強制套用指定契約組合，僅用於壓力測試；單場目標驗收請使用上方 --independent。

模擬與線上使用相同的自動戰鬥引擎。矩陣預設沿用固定技能配置；真人可在每個休息點針對下一場調整，
因此固定戰術的模擬只用於比較強度，不代表最佳技能配置的實際通關率。
