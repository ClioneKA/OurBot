# 釣魚特殊討伐

## 玩家流程

收竿時，每次實際捕獲獨立以 **0.1%** 判定 Boss 遭遇，每趟最多一隻。
基礎捕獲 2／6／20 次約有 0.1999%／0.5985%／1.9811% 的遭遇率。
釣竿追加捕獲（含改為展示大魚）多一次判定；熟練產量複製的物品不增加次數。
釣竿的稀有魚權重、料理幸運與占卜不提高 Boss 機率。中斷釣魚不判定。
正常漁獲、釣魚 XP 與大魚收藏照常取得，Boss 不取代任何捕獲。

收竿面板與完成私訊都會顯示遭遇。完成收竿回覆後立即嘗試公告，
「收竿並再次釣魚」也會觸發。新一趟釣魚不會覆蓋前一趟的待發布遭遇。

Boss 公告在獨立的「特殊討伐」頻道，提及發現者並自動報名，保留五分鐘集合時間。
冒險 Lv.1 即可加入，Boss 強度由釣場決定，不跟著發現者的釣魚或冒險等級縮放；
高階釣場的玩家可以邀請較強的隊友。發現者可照常退出，離開伺服器者不列入開戰名單。

## Boss 與食材

第一版沿用既有單體 Boss 的完整能力與平衡數值，固定普通品質，不加入隨機討伐池。

| 中庭許願池 | 許願池霸王蟹 | 巨獸／一階，週期全體橫掃 | 霸王蟹膏 | 3 |
| 魔女島湖泊 | 月露龍蝦王 | 鐵殼魔像／二階，高防禦與蓄力重拳 | 月露龍蝦尾 | 4 |
| 監獄地下水路 | 幽淵鐘鰻 | 深淵鐘龍／三階，拆鐘甲阻止全體爆發 | 鐘鰻精肉 | 5 |
| 魔女島海灣 | 星潮帝王魷 | 吞城鯨／四階，破鯨脂與水位蓄力 | 星潮厚切魷 | 5 |

勝利時，每名實際參戰者固定取得一份對應食材，發現者若實際參戰則額外一份。
倒下者仍可領獎；退出、未參戰的發現者不領獎。戰敗、平手、取消不發食材。
XP 沿用階級獎勵，金幣沿用 `[rpg.raid]`；失敗仍按現有削血比例規則給 XP／金幣。
本場不掉一般裝備、噴漆、一般肉類、香料或討伐之證，不更新頻道動態難度，
也不重排正常討伐的時間。

## 料理

每份珍貴食材提供 **幸運 1、盛宴 1、餘韻 +1**。它是一般食材，不占調味料名額，
可重複使用、出售（每份 400 金幣）或依現有物品給予規則轉送。

沿用原有五份食材規則：幸運參與主／副效果選擇，盛宴增加份數（總上限 8），
餘韻合計 2／4 時持續 2／3 場。品質、美味度、多樣性、料理等級上限、
調味料每桌最多一份等規則均不變。沒有新固定食譜、永久能力或特殊料理獎勵。

例如兩份霸王蟹膏提供幸運 2、盛宴 2、餘韻 2，仍須再選三份食材才可料理。
再加入一份粗磨岩鹽，餘韻達 4，持續三場；其他效果依完整五份配方決定。

## 頻道與排隊

- 管理員執行 `/冒險區域 建立／匯入` 可建立缺少的「特殊討伐」頻道；
  新頻道沿用討伐唯讀權限。既有頻道可在 `.env` 的 `RPG_SPECIAL_RAID_CHANNEL_IDS` 配置後匯入。
- 特殊頻道不可與一般、中階、高階頻道重複。不會在特殊頻道自動生成一般怪物，
  既有諾亞召喚仍使用中階頻道。
- 特殊討伐目前沿用 `[rpg.raid]` 的 enabled、參與人數與金幣設定。
- 依既有規則，全伺服器同時只發布一場討伐；有進行中活動或戰報待送出時排隊。
  同伺服器按遭遇建立時間處理，時間相同以遭遇 ID 排序。
- 發現者已參加其他伺服器的討伐時也等待。待發布釣魚遭遇優先於到期的普通排程，
  不改動原排程到期時間。
- 頻道不存在、Bot 無權發訊息、設定停用或伺服器不可用時保留遭遇；
  排程每次巡查會重試，不需要重新收竿，也不會重抽。

## 保存與故障恢復

`rpg_fishing_encounters` 與正常收竿獎勵在同一筆交易提交；重複收竿只讀取原結果。
遭遇綁定討伐 ID 與討伐建立也在同一筆交易提交，避免同一遭遇重複開場。
公告後沿用現有討伐保存、重啟續戰和原子結算，食材不會重複入帳。

公告發送失敗，或發送期間重啟而未保存訊息 ID，舊討伐取消、遭遇重新排隊。
Discord 發送成功但保存前崩潰，可能留下無效的舊公告；它不會開戰或給獎，
管理員可刪除。已成功保存公告後被刪除或取消的討伐不重新開場；已入帳的獎勵保留。

驗證涵蓋機率邊界、交易回滾、重複收竿、重新釣魚、同步發布、排隊、
公告失敗重試、重啟恢復、戰鬥建立、勝敗食材與重複結算，以及料理標籤與上限。
