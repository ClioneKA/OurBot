# Lv.1–70 討伐經驗平衡提案（2026-09-09）

依使用者需求：一般活躍玩家每天參加 10–15 場，先平衡至約 Lv.70，後續還會有其他練級方式。已採用本文件的建議階層 XP；比較表中的「現行」保留調整前數值作為基準。新公告討伐使用新數值，既有獎勵快照及玩家累積 XP 不追溯修改。

## 建議

先保留累積經驗曲線及現行結算公式，只調四至六階基礎 XP。以每天 12 場混打為中間情境，目標約 6 週到 70 級；60 級後每級約 1–3 天。這是設計建議，並非使用者已指定的升級期限。

目前內容範圍不必先引入個人等級經驗倍率。固定獎勵在 50–70 級仍可呈現逐漸變慢的節奏；70 級以上待後續練級內容一起規劃，不把本表當成長期至 120 級的完整解法。

| 階層 | 現行基礎 XP | 建議基礎 XP |
| --- | ---: | ---: |
| 0（史萊姆） | 1,000 | 1,000 |
| 1 | 300 | 300 |
| 2 | 450 | 450 |
| 3 | 600 | 600 |
| 4 | 750 | 1,000 |
| 5 | 900 | 2,500 |
| 6 | 1,050 | 4,500 |

四階小幅增加，五、六階拉開高階挑戰收益。以各階參考等級、普通品質及難度 1 的勝利 XP 比較：三階在 Lv.30 約占單級需求 41%，四階在 Lv.40 約占 25%，五階在 Lv.50 約占 24%，六階在 Lv.60 約占 16%。Lv.69 六階普通勝利約占升 70 需求的 6.5%；後段依然更難。

建議維持品質倍率、動態難度、失敗依削血比例發 XP 及個人既有加成；金幣與掉落不跟著此 XP 調整。

## 試算假設

- 一般活躍情境每天 10／12／15 場，另列每天 5 場休閒情境。場數是玩家實際參加的場次，並非伺服器總生成量。
- 每天 20 次有效文字獎勵、30 分鐘合資格語音。不是每日聊天上限全領。
- 一般／中階／高階的長期參戰比例假設為 40%／33%／27%；Lv.30、50 解鎖新池前，移除未解鎖的池並重新正規化。這是假設混打比例，不是排程模擬或戰報觀測值。
- 每天 12 場在 50 級後相當於平均約 4.8 場一般、4 場中階及 3.2 場高階。若主要只打某池，不能套用這個結果。
- 一般池依程式權重：史萊姆 5%、一階合計 40%、二階合計 55%；中階三階／四階為 60%／40%；高階五階／六階各半。
- 品質機率採現行 70%／20%／8%／2%，獎勵倍率為 1／1.5／3／5，全勝平均倍率 1.34。
- 勝利與失敗削血獎勵合計，假設平均領到全勝獎勵的 80%。**這不是 80% 勝率。** 為隔離 XP 方案效果，各池及品質暫共用此比例，實際需依難度、品質和隊伍等級校準。
- 頻道難度固定 1，無餐點／占卜／酒館加成。這是比較基準，不表示實際頻道長期固定在難度 1。
- 聊天按現行三次方根倍率與每日上限計算。
- 逐級用 `單級需求 / 該級預期每日收益` 累加，屬連續平均模型。没有模擬整場獎勵跨級、報名落空、活動時段、每日重置及離線天數；早期的零點幾天只表示大致活躍量，不應當作精確日曆排程。
- 未額外加入迷宮、釣魚遭遇、付費懸賞及占卜召喚。每日參戰數若已含額外召喚，不應再重複相加。未來練級來源也尚未計入。

## 候選數值比較

基準為每天 12 場混打與上述聊天量。所有方案都保留原升級曲線，不套個人等級倍率。

| 方案 | 四／五／六階 XP | 從 1 級到 70 級 | 69→70 單級 |
| --- | --- | ---: | ---: |
| 現行 | 750／900／1,050 | 66.7 天 | 5.57 天 |
| 小幅增加 | 900／1,500／2,000 | 55.4 天 | 4.51 天 |
| **建議** | **1,000／2,500／4,500** | **42.2 天** | **3.21 天** |
| 較快 | 1,200／3,000／6,000 | 37.0 天 | 2.73 天 |

建議採中間方案：未來還有其他練級來源，先保留一點加速空間。小幅增加依然讓接近 70 的玩家每天參與 12 場後，需四到五天才升級；較快方案可以作為上線後若實收偏低的調整備案。

初期 1–30 已相當快，這次不加一至三階 XP。若這不是預期的新手節奏，應另外處理，不宜把中後段調整混成全階段倍增。

## 敏感度與限制

| 獨立情境 | 建議方案从 1 到 70 |
| --- | ---: |
| 每天 5 場，聊天量同基準 | 82.1 天 |
| 每天 12 場，完全無文字或語音 XP | 50.7 天 |
| 每天 12 場、20 次文字、沒有語音 XP | 46.1 天 |
| 每天 12 場，實收為全勝獎勵的 60% | 53.3 天 |
| 每天 12 場，所有戰鬥全勝 | 34.9 天 |
| 每天 12 場全部參與最高已解鎖池 | 22.9 天 |
| 難度始終 1.5，仍能實收 80% | 29.8 天 |
| 難度始終 2.5，仍能實收 80% | 18.8 天 |
| 每天 12 場、67 次文字＋300 分鐘語音 | 21.8 天 |

除該列變動外，其他條件沿用每天 12 場基準。高難度也會改變戰果，不能把提高難度視為無代價加速；長期只參與最高池也需要足夠活動供給與可出席時間。67 次文字受整數捨去影響，不保證每級都恰好領满文字上限。

數值不是由實際戰報回歸而來，也不是戰鬥勝率模擬。它展示的是相同活動和實收條件下，XP 調整會如何改變升級速度。未來增加練級來源後，累計時間還會縮短。

## 落地與後續驗證

1. 若採用，調整 `core/rpg_monsters.py` 的階層 XP 表即可實作核心數值；相關文件與斷言同步更新。`config/settings.toml` 的 `victory_xp` 是舊快照／缺少階層資料的相容值，單改該欄無法改正常新討伐獎勵。
2. 已公告活動保留原獎勵快照；管理員明確指定最終 XP 的語意不變，現有結算冪等性也應保留。
3. 共用此階層表的釣魚特殊討伐、懸賞等會一起受影響，實作時須核對。金幣、掉落及獨立迷宮 XP 不在此數值調整範圍。
4. 懸賞可增加實際參戰場數。輪流付費召喚、偏好高階及高難度可能同時加速，42 天不是最短到 70 時間。
5. 上線後先追蹤 Lv.50–59、60–64、65–69 的每人每日場次、各池比例、實收 XP／單級需求，以及按品質和難度拆分的戰果。判斷是否真的達到約半天至三天一級的基準節奏。
6. 討伐會產生金幣、裝備和其他進度，升級不是唯一回饋。接近 70 時即使需三天升一級，也應讓每次參戰有其他可見收穫；本次未重算那些獎勵。
