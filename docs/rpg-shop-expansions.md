# 商店欄位擴充

商店以消耗貨幣分類：金幣商店販售職業裝備與料理配方擴充；討伐之證兌換提供氣球畫作與出戰配置擴充。

每位玩家在各伺服器的兩種擴充各限購五次，每次永久增加一個保存格。原有三格免費，買滿後各有八格；清空配置或配方不會收回擴充。

| 購買次數 | 出戰配置（討伐之證） | 料理配方（金幣） |
| --- | ---: | ---: |
| 1 | 20 | 2,000 |
| 2 | 40 | 4,000 |
| 3 | 70 | 7,000 |
| 4 | 110 | 11,000 |
| 5 | 160 | 16,000 |
| 合計 | 400 | 40,000 |

定價依據為程式預設的普通／中階／高階討伐報酬：每場 1／3／5 證、100／200／250 金幣。第一格約為 4 場高階討伐之證或 8 場高階討伐金幣；最後一格為 32 場或 64 場。前兩格提供較容易取得的便利，後續作為長期貨幣回收。這些場次僅作價格尺度，不含其他收入與消費，也不表示實際玩家達成時間。

購買次數與扣款在同一個資料庫交易內完成。商店顯示下一次價格、已購次數與滿額狀態；若其他商店面板已買過，舊畫面會更新報價並要求再次點擊，不會直接扣除提高後的價格。
