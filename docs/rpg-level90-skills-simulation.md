# Lv.90 技能首輪模擬與數值調整

第一輪日期：2026-09-24。以下「方法」至「尚待驗證」記錄實裝前的獨立原型；[`simulate_level90_skills.py`](../scripts/simulate_level90_skills.py) 仍可重現該次數值。正式實裝後的複驗見下一節。[技能規格](rpg-level90-skills-proposal.md) 採用本輪數值。

## 正式實裝複驗（2026-09-25）

使用 [`simulate_level90_skills_live.py`](../scripts/simulate_level90_skills_live.py) 直接呼叫正式戰鬥引擎，沿用下述四人／六人隊、兩名傳說首領與成對種子。每個場景用 100 個種子，13 組配置共 10,400 場。四個場景等權平均勝率差如下；抽樣較少，尤其不能把接近零的差距當作強弱定論。

| 新技能取代舊配置 | 勝率差 |
| --- | ---: |
| 戰線重整 | −0.8 點 |
| 浴血回斬 | +0.2 點 |
| 裂陣斬 | −1.2 點 |
| 守望壁壘 | −0.2 點 |
| 變式盾衝 | +1.8 點 |
| 制裁衝鋒 | +4.5 點 |
| 雙重毒箭 | +1.8 點 |
| 疫羽散射 | +1.3 點 |
| 催蝕箭 | +0.3 點 |
| 恩典波紋 | +2.5 點 |
| 合聲聖光 | 0.0 點 |
| 晨禱祝福 | +4.5 點 |
| 合聲聖光＋晨禱祝福 | −3.0 點 |

制裁衝鋒與晨禱祝福在這批場景有較明顯收益，但合聲聖光與晨禱祝福同時裝備會減少治療技能席位，勝率較低。正式複驗沒有出現足以支持立即更改單招數值的極端結果，因此保留原型定案數值，後續再測更多敵人數量、品質與隊伍組成。逐場景與傷害／治療數據保存在本機未納入版本控制的 `local_designs/rpg-level90-skills-live.json`。

## 方法

- 使用正式戰鬥引擎的命中、暴擊、武器穩定度、怪物機制、既有被動和 T90 商店武器／套裝。新技能效果由模擬腳本暫時處理，不寫入玩家資料庫。
- 四人隊為裝甲步兵、騎士、弓兵、僧侶各一；六人隊再加一名裝甲步兵與一名弓兵。測試角色 Lv.90，只有受測者裝備表列被動，其餘隊員無被動；沒有料理、塔羅、補給或特殊裝備。
- 對手為傳說品質星蝕巨神與逆潮聖骸，各以 300 個種子比較舊／新配置。共 13 組配置 × 4 個場景 × 300 種子 × 2 版本，合計 31,200 場。新舊組的隊伍、裝備、被動和種子相同，只有表列技能格變動；技能改變行動順序後，後續亂數消耗可能分歧。
- 「平均勝率差」是四個場景等權平均的百分點差；「個人每回合傷害」是每場總傷害除以該場回合數後取平均的相對變化。它們不是所有戰況的預測，也沒有窮舉最佳配置。接近零的勝率差尤其不能判定哪招較強。
- 弓兵的妨害射擊先於輸出技能檢查蓄力；舊箭雨與新疫羽散射都設為至少兩名敵人才施放。這兩項配置對齊避免把錯過打斷或無法施放誤算成技能倍率問題。

重現：在專案根目錄以可用的 Python 環境執行 `python -m scripts.simulate_level90_skills --seeds 300`。逐場景均值保存在本機未納入版本控制的 `local_designs/rpg-level90-skills-simulation.json`。可用 `--only 技能名稱` 與 `--passive-off` 檢查單一技能及被動消融。

## 依結果作的數值修正

| 技能 | 初稿 | 本輪提案 | 原因 |
| --- | --- | --- | --- |
| 浴血回斬 | 190% 傷害；預設 HP ≤ 60% 才施放 | 210%；預設可用就施放，低血量才自療 | 初稿因施放條件太窄而失去輸出回合。 |
| 守望壁壘 | 防禦 +60%、護盾 8%，無異常免疫 | 保留數值並加入異常免疫 | 缺少免疫會使守護職在負面狀態戰失去關鍵功能。 |
| 變式盾衝 | 140% 攻擊傷害、5 回合冷卻 | 最大 HP 的 50% 作為攻擊基礎、4 回合冷卻；命中額外取得一層連攜 | 以攻擊為基礎的版本與原衝鋒相比輸出不足。單招取代盾擊與衝鋒的測試仍顯著變弱，已放棄該目標。 |
| 雙重毒箭 | 兩次 55%，各帶兩次 30% 侵蝕；6 回合 | 兩次 75%，各帶兩次 45% 侵蝕；5 回合 | 原版短戰與長戰輸出都不足；新版較快疊毒，但每回合平均仍需和舊毒箭比較。 |
| 疫羽散射 | 每敵一段 75%＋兩次 25% 侵蝕 | 每敵三段 30%＋兩次 35% 侵蝕 | 保留多段命中對護甲與既有弓兵被動的作用，並補足延遲毒傷。 |
| 催蝕箭 | 120% 傷害 | 200% 傷害 | 提前結算侵蝕不會增加總毒傷，原本直接傷害不足以和三連矢競爭。 |
| 恩典波紋 | 即時 50%＋下回合 20% 治療量 | 即時 50%＋下回合 10% | 大隊伍的延遲治療收益明顯，先降低延遲部分。 |
| 合聲聖光 | 單體 120%＋65% 治療 | 全敵各 90%＋單體 70% 治療 | 保留與原聖光相同的範圍職責，讓樂章互動成為主要取捨。 |
| 晨禱祝福 | 全隊攻擊 +15% | 全隊 +20%，持續至下一回合結束 | +15% 版本作為祝福替代時收益不穩；+20% 在本場景有較明確的全隊價值。 |

## 尚待驗證

- 恩典波紋與晨禱祝福在六人逆潮聖骸特別有效。各追加 1,000 種子後，恩典波紋在該場景勝率由 13.6% 到 24.4%，晨禱祝福由 15.6% 到 28.0%；四人逆潮聖骸未見同樣提升。這可能是隊伍規模與首領機制的交互作用，不宜直接套用到所有副本。
- 被動消融：恩典波紋在四場景平均的勝率差，裝備恩典回響時為 +2.3 點，未裝時為 −0.8 點，顯示效果確有被動關聯。晨禱祝福裝備三重聖歌時為 +4.0 點，未裝時仍有 +3.1 點，主要收益也來自技能本身的群體加攻。
- 原型對變式盾衝只實作星蝕巨神蓄力的打斷，其他首領的同類機制、正式技能面板條件、完整戰報的護盾／間接傷害歸屬與重啟快照尚未接入。這些結果只能用來決定下一輪實作與平衡方向。
- 仍需在正式技能程式碼完成後，對精英與普通品質、單一首領與多目標戰、其他被動、特殊裝備與副本進行交叉驗證。尤其要避免高層毒傷及兩名同職業角色疊加造成異常增益。
